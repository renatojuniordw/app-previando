# 06 — AI
> Arquitetura de modelos OpenAI — hierarquia por criticidade

---

## Princípios

1. IA nunca toma decisões jurídicas — apenas estrutura e formata
2. Output sempre é template — advogado revisa obrigatoriamente
3. Temperatura 0 para extração, 0.3 para texto
4. Input sempre sanitizado antes do prompt
5. Custo monitorado por geração
6. Modelo centralizado em `src/lib/ai-models.ts` — nunca hardcoded

---

## Hierarquia de Modelos

O Previando opera com dois níveis de modelo, separados por criticidade da tarefa:

| Nível | Constante | Modelo | Quando usar |
|---|---|---|---|
| CRITICAL | `AI_MODELS.CRITICAL` | `gpt-4.1-mini` | Extração CNIS, pareceres jurídicos, diagnóstico de prontuário |

**Por que gpt-4.1-mini para tarefas críticas?**
O CNIS é traiçoeiro: vínculos quebrados, múltiplos NITs, contribuições extemporâneas, períodos concomitantes. Um modelo menos capaz tende a simplificar demais ou dropar detalhes — o que vira cálculo errado e perda de confiança do advogado. Confiança é o ativo principal do Previando.

## Controle de Custo

```typescript
// Estimativa por operação (gpt-4.1-mini):
// Parse CNIS:      ~20.000 tokens = ~$0.016  (R$ 0,09)
// Parecer:         ~3.000 tokens  = ~$0.0024 (R$ 0,01)
// Diagnóstico:     ~2.000 tokens  = ~$0.0016 (R$ 0,01)

// 50 usuários × 20 ops/mês:
// CNIS (50×5):     ~$4.00/mês
// Pareceres (50×20): ~$2.40/mês
// Total estimado:  ~$7/mês (R$ 38) — ainda margem confortável
```

## Rate Limit de IA

```typescript
// 20 gerações de parecer por hora por usuário (via Redis)

if (!limit.success) throw new RateLimitError('Limite de pareceres/hora atingido.')

// 10 diagnósticos por hora por usuário
const limit = await rateLimit(`diagnosis:${userId}`, 10, 3600)
```

---

## Regras Globais

1. Temperatura 0 para extração, 0.2-0.3 para texto
2. Max tokens sempre definido — nunca aberto
3. Timeout 180s — cobre CNIS de 20+ páginas
4. Todo prompt salvo em `opinions.promptUsed` (auditoria)
5. Todo custo salvo em `opinions.generationCostUsd`
6. Advogado sempre revisa — UI não permite usar parecer sem abrir o editor
7. Rodapé "Previando" em todo parecer gerado
8. Modelo nunca hardcoded — sempre via `AI_MODELS.*`
