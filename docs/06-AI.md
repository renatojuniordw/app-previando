# 06 — AI
> GPT-4o mini — Extração CNIS, Pareceres e Checklist

---

## Princípios

1. IA nunca toma decisões jurídicas — apenas estrutura e formata
2. Output sempre é template — advogado revisa obrigatoriamente
3. Temperatura 0 para extração, 0.3 para texto
4. Input sempre sanitizado antes do prompt
5. Custo monitorado por geração

---

## Geração de Parecer

```typescript
// System prompt (trecho)
`Você é um assistente especializado em direito previdenciário brasileiro.
Estruture um parecer preliminar técnico com base nos dados fornecidos.

REGRAS ABSOLUTAS:
1. Use APENAS os dados fornecidos — nunca invente informações
2. Não faça afirmações categóricas sobre aprovação pelo INSS
3. Sempre inclua: "Este parecer é preliminar e não substitui análise jurídica completa"
4. Máximo 4 parágrafos — seja objetivo
5. Nunca citar leis sem certeza absoluta`

// Rodapé obrigatório no parecer gerado:
// "Calculado via Previando (app.previando.com.br)"
```

## Controle de Custo

```typescript
// Preços GPT-4o mini (2025)
// Input:  $0.15 / 1M tokens → ~$0.00015 por 1000 tokens
// Output: $0.60 / 1M tokens → ~$0.00060 por 1000 tokens

// Estimativa por operação:
// Parse CNIS:  ~3000 tokens = ~$0.0005 (R$ 0,003)
// Parecer:     ~2500 tokens = ~$0.0004 (R$ 0,002)
// 50 usuários × 20 ops/mês = ~$0.50/mês (R$ 2,50)
```

## Rate Limit de IA

```typescript
// 20 gerações de parecer por hora por usuário (via Redis)
const limit = await rateLimit(`ai:${userId}`, 20, 3600)
if (!limit.success) throw new RateLimitError('Limite de pareceres/hora atingido.')
```

---

## Regras Globais

1. Temperatura 0 para extração, 0.2-0.3 para texto
2. Max tokens sempre definido — nunca aberto
3. Timeout 30s — se demorar mais, é erro
4. Todo prompt salvo em `opinions.promptUsed` (auditoria)
5. Todo custo salvo em `opinions.generationCostUsd`
6. Advogado sempre revisa — UI não permite usar parecer sem abrir o editor
7. Rodapé "Previando" em todo parecer gerado
